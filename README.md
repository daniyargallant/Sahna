# Сцена

Караоке для большого экрана: видео YouTube играют прямо в приложении через встроенный плеер, очередь певцов, каталог из ~200 популярных песен. Гости добавляют песни со своих телефонов.

## Запуск

Нужен Node.js 18+.

```
npm install
npm start
```

Откройте на компьютере, подключённом к телевизору, http://localhost:3030. Открывать `public/index.html` двойным щелчком (`file://`) нельзя: плеер YouTube, каталог и пульт там не работают.

Переменные окружения:

- `PORT` — порт (по умолчанию 3030);
- `PUBLIC_URL` — адрес, который зашивается в QR-код (например `https://scena.onrender.com` или адрес туннеля). Обычно не нужен: сервер берёт адрес, по которому открыт экран, а если это `localhost` — IP компьютера в локальной сети.

## Телефон как пульт

При открытии экран получает комнату с кодом из 4 цифр. По умолчанию на экране только видео, под ним панель «Поёт сейчас» и QR-код «Отсканируйте на телефоне» с числом подключённых телефонов. QR также показан на заставке «Сцена свободна» и между песнями. Нажмите на QR, чтобы показать его крупно вместе с кодом и ссылкой — для тех, у кого не сканируется.

Очередь, каталог, свои ссылки и итоги вечера — в панели ведущего: кнопка рядом с QR или клавиша P. Экран запоминает, открыта панель или нет.

Гость сканирует QR (или открывает `адрес/r/КОД`), вводит имя, ищет песню в каталоге и нажимает «Спеть». Песня встаёт в очередь на экране с его именем. Гость видит, что играет сейчас, и всю очередь, свои песни подсвечены. Кнопкой «Следующая песня» гость может переключить песню на телевизоре — телефон сначала предупреждает, что песня прервётся для всех. Переключается только та песня, которую гость видел, поэтому два одновременных нажатия не пропустят две песни. Пауза и порядок песен — только на экране.

Дома или в кафе телефон должен быть в той же Wi-Fi сети, что и компьютер. Windows при первом запуске может спросить про доступ Node.js к сети — разрешите для частных сетей.

Очередь хранится на экране (в браузере), сервер только пересылает сообщения. Если экран перезагрузить или сервер перезапустится, экран вернёт себе тот же код комнаты, и телефоны переподключатся сами.

### Порядок очереди

Переключатель над очередью:

- **По порядку** — песни идут в порядке добавления, их можно двигать стрелками;
- **По кругу** — певцы чередуются: за круг каждый поёт по одной песне, первыми идут те, кто давно не пел. Если Аня добавила три песни, а Бека одну, порядок будет Аня, Бека, Аня, Аня.

## Каталог и видео

- `data/catalog.json` — список песен: `id`, `title`, `artist`, `language` (`ru`/`kk`/`en`), `decade` (`1980`, `2010`… или `null` для народных и классических казахских песен), `genre`, `tags` (`дуэт`, `медленная`, `танцевальная`, `для компании`). Только названия и исполнители, тексты песен не храним.
- `data/videos.json` — найденные караоке-видео, до 3 кандидатов на песню. Заполняется скриптом ниже.
- `data/bad-videos.json` — видео, которые не открылись во встроенном плеере (ошибки 100/101/150). Плеер сам пишет сюда и переключается на следующего кандидата; сервер больше не отдаёт эти видео, а скрипт ищет замену.

Песня без видео видна в каталоге с пометкой «Нет видео». Добавить свою песню можно на вкладке «Мои» по ссылке YouTube.

### Ключ YouTube Data API

1. Откройте https://console.cloud.google.com/ и создайте проект (бесплатно).
2. «APIs & Services» → «Library» → найдите **YouTube Data API v3** → «Enable».
3. «APIs & Services» → «Credentials» → «Create credentials» → «API key».
4. Желательно ограничить ключ: «Edit API key» → «API restrictions» → только YouTube Data API v3.
5. Скопируйте `.env.example` в `.env` и впишите ключ:

```
YOUTUBE_API_KEY=AIza...
```

Файл `.env` в `.gitignore` и в репозиторий не попадает. Ключ нужен только скрипту на компьютере, браузер его не видит.

### Поиск видео

```
npm run resolve
```

Для каждой песни скрипт ищет «исполнитель название караоке» (для английских — «karaoke»), берёт только встраиваемые видео длиной 2–8 минут со словами karaoke/караоке/минус/instrumental в названии и сохраняет до трёх лучших.

Квота: поиск стоит 100 единиц, проверка — 1, бесплатный лимит 10 000 в сутки, то есть около 99 песен в день. Весь каталог займёт три дня. Скрипт можно запускать сколько угодно раз: найденные песни пропускаются, на исчерпанной квоте он останавливается и пишет, сколько осталось.

Параметры:

- `--limit=10` — не больше 10 песен за запуск;
- `--retry` — ещё раз искать песни, для которых ничего не нашлось;
- `--only=ru-001,en-014` — только эти песни (повторный поиск).

Обходить запрет на встраивание (прокси, скачивание видео) приложение не пытается: такие видео просто пропускаются.

## Отчёт о нерабочих видео

Каждая ошибка плеера пишется в консоль браузера (F12) таблицей; полный список за вечер — команда `scenaReport()` в консоли. Сервер тоже печатает строку `[плеер] не играет …`.

## Во время вечера

- **Реакции.** Пока идёт песня, на телефонах есть кнопки 👏 🔥 ❤️ 😂. Значки с именем гостя взлетают в панели «Поёт сейчас» под видео (поверх самого плеера YouTube ничего не рисуется), там же копится счётчик. Один телефон — не больше 12 реакций за 5 секунд.
- **Темп.** Под названием песни на экране — 0,75× / 1× / 1,25× (только у ведущего). Темп выбирается для каждой песни отдельно, следующая начинается с 1×.
- **Избранное и история.** Гость отмечает песни звёздочкой, на вкладке «Моё» видит избранное и что уже пел, и может спеть снова. Всё хранится на экране по имени певца, поэтому с другого телефона под тем же именем список тот же.
- **Счёт по микрофону.** Когда песня гостя играет, на его телефоне появляется «Включить микрофон». Телефон оценивает, сколько человек пел, громкость, выразительность и ровность ритма — это игра, с оригиналом голос не сравнивается. Звук не записывается и никуда не отправляется, на экран уходит только число. Итог приходит на экран в конце песни. **Браузеры дают микрофон только по https**, поэтому счёт работает на размещённой версии (Render, Railway), а по адресу вида `http://192.168.…` кнопки не будет.
- **Итоги вечера.** Вкладка «Вечер» на экране: сколько песен и певцов, звезда вечера, хит (больше всего реакций), лучший счёт, все выступления. «Итоги на экран» показывает их крупно, когда ничего не играет. «Новый вечер» обнуляет журнал, избранное и история певцов остаются.

## Размещение в интернете

Тогда телефонам не нужна общая Wi-Fi сеть с экраном. Сначала найдите видео (`npm run resolve`) и сохраните `data/videos.json` в репозиторий: на бесплатных хостингах диск стирается при перезапуске, поэтому скрипт там не запускают. Ключ API на хостинг не нужен.

Перед этим положите проект на GitHub (`git init`, коммит, `git push`). `.env` и `node_modules` в репозиторий не попадут.

### Render

1. https://render.com → «New» → «Blueprint» → выберите репозиторий. Render прочитает `render.yaml` (бесплатный тариф, Франкфурт).
2. После сборки откройте выданный адрес вида `https://scena-xxxx.onrender.com` на компьютере у телевизора.

Бесплатный сервис засыпает после 15 минут без запросов, первое открытие после сна занимает до минуты. Откройте экран заранее, перед приходом гостей. Если сервис всё-таки перезапустится, экран сам переподключится с тем же кодом комнаты.

### Railway

1. https://railway.app → «New Project» → «Deploy from GitHub repo».
2. Railway сам увидит Node.js и запустит `npm start`. Порт он передаёт в `PORT`, приложение его подхватит.
3. «Settings» → «Networking» → «Generate Domain».

`PUBLIC_URL` на хостинге задавать не нужно: QR-код строится по адресу, с которого открыт экран.

## Клавиши

Пробел — играть/пауза (во время заставки — начать сразу), N — следующая песня, F — полный экран, P — только видео.
